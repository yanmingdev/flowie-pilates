# Flowie 設計基準與畫面驗收

設計參考為本資料夾的 `flowie-brand-reference.png`，其圖像不是網站實際截圖。網站使用獨立的主視覺、課程圖片與以葉片／F 為概念重新繪製的標誌。

| 項目 | 實作 |
|---|---|
| 基本色 | 鼠尾草綠 `#849A86`、奶茶米白 `#F7F3EE`、柔霧粉 `#E9CFC9`、可可棕 `#514A45`。 |
| 手機首頁 | 白色導覽、照片主視覺、標題與預約按鈕、近期課程卡片、五個快捷功能、底部五項導覽。 |
| 元件 | 圓角卡片、留白、柔和陰影與一致的線條圖示；對話框使用 Radix accessible primitives。 |
| 資料來源 | 網站文案、Banner、課程、圖片網址、公告與區塊排序由資料庫提供；導覽與版面為程式。 |

因真實文字長度、動態資料和手機尺寸會變化，首頁並非逐像素複製原圖；Logo 重新繪製，主視覺照片也不同於參考。`docs/screenshots` 的截圖是實際執行頁面，資料來自本機 PostgreSQL，Auth／Storage 使用測試替身；不代表已連線正式服務。
