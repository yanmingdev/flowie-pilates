# Flowie 專案審查與分層整理

基準：使用者附件 `flowie-pilates(5).zip`。日期：2026-11-18（Asia/Taipei）。本次僅整理架構、檔案責任及驗證，沒有新增功能、改版 UI 或改變資料模型。

## 審查結論

現行啟動路徑確實使用 React 18＋Vite 6、Express 4 與 Supabase，並非沒有框架。React Router、TanStack Query、React Hook Form／Zod、Radix UI、FullCalendar 與 PWA 沿用原有整合。主要問題是上次拆分後，整套舊實作仍留在現行 src，舊測試／腳本／SQL 也和新位置並存，文件又聲稱未打包 Git，與這次保留 Git 的要求不符。

Mantine 官方定位為 React components library；它提供 UI 元件、Provider 與主題系統，不能取代應用分層。本案未安裝 Mantine，已有 Radix UI 和品牌樣式，因此本次沿用原方案，不平白增加第二套 UI 系統。參考：https://mantine.dev/about/ 、https://mantine.dev/getting-started/ 。React 官方亦有 React＋Vite 的建置方式：https://react.dev/learn/build-a-react-app-from-scratch 。本次套件版本以附件 lockfile 為準，不因文件最新版而升級。

## 實際調整

| 發現 | 處理 |
|---|---|
| 舊 frontend/src/pages、components、services、lib、routes 與新版重複 | 現行只維護 app／features／shared；舊內容封存，不再編譯或 lint |
| 舊 backend app、整包 routes、middleware、controller、repository 與新版模組並存 | 只保留 index→server→createApp→模組 routes→controller→service→repository／RPC |
| bootstrap 同時持有多層 Provider 組裝 | 抽至 app/providers/AppProviders.tsx，原 Query 策略與 Provider 順序維持 |
| backend/tests、frontend/tests 與 tests 重複；scripts 有舊測試入口 | 只維護 tests；44 個重複程式／設定／測試檔案原始位元組保留於 archive |
| 舊 SQL、legacy 參考樹與現行 SQL 並存 | 原舊樹封存；現行只使用 supabase/sql |
| .prettierrc.json 與 prettier.config.cjs 兩個設定入口 | 保留標準入口轉交 config/tooling，移除內容相同的舊設定 |
| 架構檢查忽略 re-export 與覆蓋殘留舊檔 | 補 re-export 依賴檢查與 44 個舊路徑禁止重現檢查 |
| 靜態路由檢查對動態資源路由採固定清單 | 新增測試，從 Express 真正註冊的 router 比對全部原路由 |
| 說明文件寫「不含 .git」 | 重寫現行 README、架構及替換說明；封存上版驗證輸出 |

`removed-duplicates.json` 列出 44 個移出現行目錄檔案及原始 SHA-256；`PATH_MAP.md` 列出舊新路徑對照。archive 中的參考內容不參與啟動、建置、測試或 migration。

## 保持不變

- 原套件清單及 lockfile；npm workspaces、Node 24.x、TypeScript 設定。
- 既有前端 URL、68 個 API 路由、HTTP／RPC 契約、既有 501 端點。
- 會員／老師／管理員權限、使用者 JWT、Supabase RLS／受控交易。
- 01～07 現行 SQL、ER 圖、資料庫欄位與初始資料。
- 現行樣式展開指紋、品牌圖片、RWD／PWA 策略。
- 附件中的環境設定；不在報告中列出 key。
- `.git` 全部檔案內容；物件、index、HEAD、分支、config 及 reflog 均保留。

## 驗證邊界

實際執行結果與數量見 `docs/verification/RESULTS.md`。測試使用隔離本機資料庫、模擬 Auth 或公開資料 fixture；沒有將資料寫入正式 Supabase，也沒有驗證真實寄信或實體手機安裝。既有 any、部分 HTML 控制項與歷史 CSS override 不在這次架構整理中全面改寫，不能將通過檢查解讀為所有業務情境皆已驗收。
