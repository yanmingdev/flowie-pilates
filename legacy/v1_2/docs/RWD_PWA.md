# RWD / PWA

介面以手機優先：學生端手機底部導覽、卡片和可捲動對話框；桌面管理側欄和表格。FullCalendar 提供月、週、日及列表，窄螢幕預設週列表。

本次在隔離資料與模擬 Auth 的瀏覽器環境，於 320×568、375×812、430×932、768×1024、1280×800、1440×900 測試學生首頁、課程探索、管理 Dashboard 和行事曆的水平溢出；375 寬度另檢視預約視窗。嵌入式 viewport 的可用寬度會扣除瀏覽器捲軸；這不是所有頁面、表單或實際設備的完整驗收。畫面截圖在 `docs/screenshots`。

Vite PWA 產生 manifest、192／512 圖示和 service worker；預先快取 app shell、JS、CSS 與圖示，不快取業務 API，範例首頁／課程圖片也不預先快取。離線時顯示提示，交易必須連線；登出清除 React Query 快取。新版本由使用者決定更新。

正式 PWA 需要 HTTPS（localhost 除外）。Android Chrome 可使用瀏覽器提供的安裝選項，iOS Safari 可從分享選單加入主畫面。實機 PWA 安裝、離線、更新與登出隱私尚未驗證，不能視為已通過。
